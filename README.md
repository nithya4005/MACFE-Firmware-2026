# MACFE-Firmware-2026

A C++ program that prints "Hello World" and greets the user by name.

## Prerequisites

Make sure you have g++ installed:

```bash
g++ --version
```

## Setup

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/MACFE-Firmware-2026.git
cd MACFE-Firmware-2026
```

## Compile

```bash
g++ -o hello main.cpp
```

## Run

```bash
./hello
```
